# Gestion Location Arc

Plugin WordPress conçu pour les clubs de tir à l’arc afin de gérer les locations d’arcs, la gestion du matériel, la génération des contrats et leur suivi

---

## Fonctionnalités

- Gestion des locations d’arcs : création de contrat, suivi du paiement, échéances, renouvellement, dashboard
- Gestion des prêts de matériel
- Suivi de l’inventaire : état du matériel, montant et date d'achat
- Suivi du matériel disponible : page pour les adhérents pour afficher le matériel disponible
- Affectation du matériel aux adhérents via les contrats
- Génération automatique des contrats PDF avec la librairie DomPDF
- Historique des locations
- Interface d’administration responsive
- Gestion des échéances et cautions
- Recherche et filtres avancés
---

## Impact

Le plugin est actuellement utilisé en production au sein du club pour gérer une soixantaine de locations et prêts de matériel.

Il a permis :
- de supprimer les fichiers Excel partagés,
- de centraliser les informations matériel et contrats,
- de simplifier le suivi des locations,
- de réduire les erreurs de saisie,
- d’automatiser la génération des contrats PDF,
- d’améliorer le suivi du matériel disponible,
- d’accélérer les opérations réalisées par les bénévoles du club.

L’objectif du projet était avant tout de fournir un outil simple, concret et réellement utilisable au quotidien par une association sportive, afin de soulager la charge de travail des bénévoles

## Contexte du projet

Ce plugin a été développé pour répondre aux besoins du club d'Issy-les-Moulineaux, gérant plusieurs dizaines de locations et prêts de matériel.

L’objectif était de remplacer les fichiers Excel et les suivis manuels par une application web centralisée, simple d’utilisation et accessible depuis n’importe quel appareil.

## Installation

```bash
1. Copier le dossier du plugin dans /wp-content/plugins/
2. Copier le dossier Vendor dans /wp-content
3. Activer le plugin depuis l’administration WordPress
4. Configurer les paramètres du plugin
```
